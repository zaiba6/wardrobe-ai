# i have nothing to wear.ai — browser extension

Right-click any image on the web and save it directly to your inspo board.

## Install (Chrome / Arc / Brave / Edge)

1. Open your browser and go to `chrome://extensions`
2. Enable **Developer mode** (toggle in the top right)
3. Click **Load unpacked**
4. Select the `extension/` folder from this repo

## Setup

1. Click the extension icon in your toolbar
2. Paste your app URL (e.g. `https://wardrobe-ai-production-c5eb.up.railway.app`)
3. Click **test connection** to verify
4. Click **save**

## Usage

Right-click any image on Pinterest, Instagram, or anywhere → **Save to inspo board ✦**

A ✓ badge on the extension icon means it saved. A ✗ means something went wrong.
